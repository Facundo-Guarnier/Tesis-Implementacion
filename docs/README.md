# 🚦 Documentación del Proyecto: Semáforos Inteligentes

Bienvenido a la documentación central del proyecto. Este directorio contiene toda la información necesaria para comprender, configurar, y contribuir al desarrollo del sistema de semáforos inteligentes.

A continuación se detalla la estructura y el contenido de cada sección.

## 📚 Estructura de la Documentación

### 1️⃣ Configuración Inicial (`/1_setup`)

Guías para configurar el entorno de desarrollo desde cero.

- **[`dependencies.md`](./1_setup/dependencies.md)**: Lista de librerías de Python y paquetes del sistema necesarios para ejecutar el proyecto.
- **[`project_structure.md`](./1_setup/project_structure.md)**: Descripción de alto nivel de la estructura de carpetas y el propósito de cada componente.
- **[`vscode_setup.md`](./1_setup/vscode_setup.md)**: Instrucciones para configurar Visual Studio Code y las extensiones recomendadas para un desarrollo consistente.

### 2️⃣ Guías y Convenciones (`/2_guides`)

Reglas y buenas prácticas que deben seguirse durante el desarrollo.

- **[`code_style.md`](./2_guides/code_style.md)**: Convenciones sobre el estilo del código Python, incluyendo nombres de variables (snake_case, CamelCase) y formato general.
- **[`contributing.md`](./2_guides/contributing.md)**: Flujo de trabajo con Git, formato de commits (Conventional Commits) y el proceso para crear Pull Requests.
- **[`tooling.md`](./2_guides/tooling.md)**: Detalles sobre las herramientas automáticas de calidad de código (`ruff`, `black`, `mypy`, `isort`) y cómo funcionan.

### 3️⃣ Información de Referencia (`/3_reference`)

Documentos de consulta sobre la lógica específica y los detalles técnicos del proyecto.

- **[`yolo_model_info.md`](./3_reference/yolo_model_info.md)**: Información sobre el modelo de detección de objetos YOLO, incluyendo la lista de clases que puede identificar.
- **[`traffic_logic.md`](./3_reference/traffic_logic.md)**: Definición de los estados y fases de los semáforos utilizados en la simulación.
- **[`external_references.md`](./3_reference/external_references.md)**: Recopilación de enlaces, comandos y recursos externos útiles para el proyecto (SUMO, tutoriales, etc.).
